# Digitales Bürgerportal

Kleine administrative Webanwendung zur Bearbeitung von Bürgeranfragen.

## Funktionen
- Bürgeranfragen erfassen
- Formularvalidierung
- Übersicht eingereichter Anfragen
- Administrative Bearbeitung

## Technologien
- HTML5
- CSS3
- JavaScript

## Ziel des Projekts
Dieses Projekt dient dem Aufbau praxisnaher Kenntnisse im Bereich Verwaltungsdigitalisierung und moderner Webentwicklung.
